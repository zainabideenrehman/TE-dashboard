Use only when the briefing lists screening questions. Read
`_reference/voice-rules.md` and `_reference/portfolio/_index.md`, then the
1-2 anchor files needed.

## Rules
- 100-200 words per answer, depending on depth. Concise but specific.
- Same voice rules as the proposal (plain language, no banned buzzwords,
  zero em dashes, no exclamation marks, contractions natural, first person).
- EVERY answer grounded in a real portfolio project. No generic answers.
- Same anchoring rules (AutoCar for automotive, Ludooka for kids edu, etc.).
- Unfamiliar territory: be honest about the gap, map the closest experience.
  Never fabricate.

## Format
**Q1: [question text]**
[answer]

**Q2: [question text]**
[answer]
